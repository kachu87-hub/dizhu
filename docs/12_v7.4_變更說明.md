# 砥柱 DiZhu v7.4 變更說明（加樁表移到圖面加樁工具卡）

基準：v7.3 交接包（含 DEM）。只改 tcv4/xpmod.js（檔尾新增 xpMoveStaBlock／xpBadge，另加樁表點名欄改靠左）；patch.py 只改版本字樣 v7.4。

## 變更
- 「📍 自行加樁號」整區（里程、點名、加入、清空、圖面點擊加樁、加樁表）從「📐 里程樁號與路寬/河寬設定」卡移到「🛣️ 中心線定線與圖面加樁工具」卡最上方（卡片標題正下方），原位置不再出現。
- 卡片標題徽章由「6 點」改為「6 點・加樁 2」（自行加樁數；多中心線匯流樁不計）。加樁、改樁號、刪除、復原、讀檔後即時更新。
- 搬移是在頁面載入後用 DOM 移動，元素 id 與函式都不變，存讀檔、復原、測試腳本不受影響。

## 驗證
- tests/ 35 支全部通過（新增 p9_xpui.js：區塊在該卡片標題下、加樁表在卡內、徽章「加樁 1」→ 加入後「加樁 2」）。
- 無 DEM 時全圖 DXF 長度 9556658，與 v7.3 相同。
