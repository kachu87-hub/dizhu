# 砥柱 DiZhu v8.3 變更說明：介面圖示、浮動列膠囊、底部資料抽屜＋改樁號連動

基底：v8.2（3D 改版）。這一版只新增一個模組 tcv4/v83mod.js（串在 v3dmod 之後），patch.py 只改模組串接和版本字樣。計算、數量、DXF 都沒有改（全圖 DXF 長度 9556658，與 v8.2 相同）。
這次做的項目：U1、U2、U4、K1、K2、K3。U3、U5、K4 沒有做。

## U1 頂部按鈕加圖示
- 4 個視圖、中心線、開啟 DXF、另存專案、載入、檢核、匯出、設定，都加上和左側圖示欄同一套單色線條圖示。
- 視窗寬度不夠時，會自動分兩段只顯示圖示，名稱改成滑鼠移上去時顯示：
  1. 先藏「開啟 DXF、另存專案、載入、設定、中心線」的文字（1366 寬、介面倍率 1.15× 時是這一段）。
  2. 還是放不下時，再藏 4 個視圖、匯出、檢核的文字。
- 改介面倍率或視窗大小時會重新判斷。

## U2 縱斷、橫斷、3D 浮動列改成單排膠囊
- 三個視圖的浮動列都改成畫布上方置中的單排膠囊，外觀相同，按鈕都有圖示。
- 橫斷面：按鈕改成「矩陣總覽」「單樁放大」「上一樁」「下一樁」（完整名稱在滑鼠提示裡）；「選擇樁號：」文字和分隔線拿掉；「矩陣：單擊選取、雙擊放大」改成滑鼠提示。
- 放不下的項目會從後面依序收進「⋯ 更多」，例如顯示範圍、結構線優先，必要時連下一樁也會收進去。各下拉選單和輸入欄的 id 沒變，功能和原本相同。
- 縱斷面那條原本橫跨整個畫布，現在縮成「縱斷面｜說明」的小膠囊。按「說明」會在膠囊下方展開操作說明，不會把膠囊撐成兩排。3D 也一樣。

## U4 底部資料抽屜
- 畫布下方新增一條全寬資料抽屜，有三個頁籤：樁號表（縱斷面里程樁號表，16 欄）、實測展點表、IP 要素表。頁籤上會顯示筆數。
- 點頁籤可以打開；再點同一個頁籤，或按右側的 ▾，可以收合。收合時只留一條 26 px 高的頁籤列。
- 打開時畫布會自動縮短，不會蓋住圖。抽屜上緣可以拖拉調整高度。開關狀態、高度和目前頁籤都會記在這台電腦的瀏覽器裡。
- 左側原本放表格的卡片，改成顯示「表格已移到畫面下方的資料表。［開啟］」。
- 平面圖「平曲線 IP 要素表」的「完整編輯」，以前是另開一個浮動視窗，現在改成打開抽屜的 IP 要素表頁。
- 縱斷、橫斷時點左側的「樁號表」圖示，會一起打開抽屜的樁號表。
- 表格內容和點列跳轉都沒有改（點樁號表任一列＝選取該樁）。
- 注意：在橫斷面「矩陣總覽」打開抽屜時，畫布變矮，每張小斷面也會跟著變扁。要看清楚時，可以先收合抽屜，或改用「單樁放大」。

## K1 移動加樁時，接在加樁上的端點一起移動
- 在加樁表修改樁號，或在平面圖拖曳加樁的 ◆ 時，起訖點在原樁號 0.01 m 以內的物件端點，會跟著移到新樁號。適用的物件有：護岸（含加高段、變寬段）、排水溝（沿中心線型）、整地（含分段）、護坡基礎補強。
- 如果移動後會超過該物件的另一端，那個端點不動，狀態列會列出來。
- 刪除加樁時，物件端點留在原里程，物件不會被刪掉。

## K2 移動結構物時，接在結構物上的端點一起移動
- 修改結構物卡片的樁號欄，或修改縱斷面落差表的樁號時，起訖點接在該結構物上的端點會一起移動，適用的物件同 K1。
- 附屬的副壩、固床工也算在內：它們隨主壩移動後，接在它們上面的端點也會跟著移動。
- 例如 u.tcproj 把固床工 1 從 0K+220.25 改成 0K+225，右岸護岸 2 的迄點也會跟著變成 0K+225。

## K3 改起點樁號時全部一起平移
- 修改「里程樁號與路寬／河寬設定」的起點樁號時，會先跳出確認視窗：
  - 「確定」＝一起平移：結構物、護岸（含加高、變寬、曲線控制點、生物通道）、排水溝（沿中心線型）、整地（含分段與個別樁設定）、護坡基礎補強、加樁、縱斷面 VIP 與落差、水力分段流量與糙度、各樁手動資料（河寬、讀取長度、偏角、上下斷面、地面修正、左右側高），以及縱斷面圖的標示區段，全部加上差值。這樣物件在圖上的位置不變，土方也不變。
  - 「取消」＝只改數字：物件維持原本的里程數字，和以前一樣。
- 只會平移目前這條中心線的資料。
- 專案裡還沒有任何物件時，不會跳出確認視窗。
- 限制：等距樁（例如每 20 m）是從起點樁號往後算。差值不是樁距的整數倍時，等距樁會落在新的位置，原本設在舊等距樁上的手動資料會留在舊里程數字上。

## Ctrl＋Z 復原
- 結構物和護岸原本不在 Ctrl＋Z 的紀錄裡。K1、K2、K3 這三種動作會另外記下結構物樁號、護岸各段樁號、起點樁號和標示區段，所以按一次 Ctrl＋Z 可以全部還原。
- 其他動作的復原方式和以前相同。
