# 橫斷面看平面位置＋加樁管理：待改項目（請勾選）

基準：v6.9。尚未改任何程式。勾好後合在同一版一起改。

## 調查結果
- 介面 3 目前只畫橫斷面；要確認斷面線與現地構造物（匯入 DXF 線、等高線、護岸、結構物）的相對位置，只能切回介面 1。v6.9 的「↻ 平面點選方向」也會把畫面切到介面 1。
- 加樁存在 `state.customStations`（[{s, name}]）。介面只有三個入口：輸入里程「加入」、「清空」（全部刪）、「📍 圖面點擊加樁」，加上橫斷面卡的「加樁（輸入里程）」。清單只是一行文字「已加樁：…」，**沒有單筆刪除、沒有改里程、沒有改點名**，目前只能全部清空或 Ctrl＋Z。
- 各樁的手動資料都用樁號當鍵：河寬／護岸控制值 `secParams`、讀取長度與偏角 `secExt`、上下斷面 `splits`。改樁號時若不一起搬，這些資料會留在舊樁號（變成孤兒）。
- 多中心線匯流產生的加樁（帶 `cf` 標記）是自動算的，不能手改。

## 第 1 點：在介面 3 直接看平面相對位置
- [ ] **A1 平面小視窗（子母畫面）**：橫斷面圖角落浮一個可拖曳、可調大小、可收合的平面視窗。內容就是介面 1 的圖（底圖、DXF 現地構造物、等高線、護岸、結構物、排水溝），圖層開關跟介面 1 同步。自動以目前斷面中心置中，換樁號、改 θ 即時更新。滾輪縮放；可切「北朝上」或「斷面朝上」（斷面線轉水平、左岸在左，跟橫斷面圖同向，建議預設）。
- [ ] **A2 游標雙向對位**：在橫斷面圖上移動游標，小視窗同步在斷面線上標出該點（顯示「距中心 L 6.3 m」）；在小視窗滑過斷面線，橫斷面圖畫一條對應的垂直參考線。
- [ ] **A3 在小視窗直接調偏角**：在小視窗拖曳斷面線端點即改 θ（可用 F3 鎖點對準岸邊特徵點），橫斷面圖即時跟著重畫。「↻ 平面點選方向」改成在小視窗操作，不再切回介面 1。
- [ ] **A4 現地構造物交點標註**：斷面線與匯入 DXF 線的交點，在橫斷面圖上畫垂直虛線並標圖層名（例：既有擋土牆、道路邊線）。預設只在畫面顯示，可勾選是否輸出到 DXF。
- [ ] **A5 相鄰斷面淡顯**：小視窗中前後斷面線淡灰顯示，與目前斷面交叉時變紅（v6.9 只有文字「⚠ 斷面交叉」）。

## 第 2 點：樁號調整與刪除加樁
- [ ] **B1 加樁表**：「自行加樁號」下方那行文字改成表格，每列：樁號（可直接改里程）、點名（可改）、［看］跳到該樁橫斷面、［✕］刪除單筆。匯流樁列灰色唯讀。「清空」保留但加確認。
- [ ] **B2 改樁號時資料一起搬**：改里程時，該樁的河寬／護岸控制值、讀取長度、偏角、上下斷面一起搬到新樁號；新樁號跟既有樁號重疊（±0.01 m）時擋下並提示。刪除加樁時一併清掉這些資料。都可 Ctrl＋Z 復原。
- [ ] **B3 橫斷面編輯卡加按鈕**：「修改此樁號」「刪除此加樁」，只對自行加樁有效（等距樁、曲線樁、結構物樁停用並說明原因）。
- [ ] **B4 平面圖上直接拖曳加樁**：在介面 1 點選加樁後可沿中心線拖曳改里程（游標顯示里程，可鎖點），按 Delete 刪除。
- [ ] **B5（可選）等距樁／曲線樁個別「不出斷面」**：在表中勾選後該樁不產生橫斷面、不入土方、不出圖（不改中心線樁距）。會影響土方間距，建議先不做，有需要再加。
