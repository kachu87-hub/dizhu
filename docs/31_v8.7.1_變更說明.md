# 砥柱 DiZhu v8.7.1 變更說明（2026-11-15）

v8.7.1 ＝ v8.7 ＋ 以下四項（依使用者 11/14～11/15 回報一起修改）。46 支回歸測試全部通過（含新增 p18_v871）。

## 一、畫中心線時平移，中心線不再消失

**原因**：畫中心線途中按「✋ 平移／改 IP」或右側「平移」按鈕，程式會切回平移工具，並清掉還沒完成的點（原主程式就是這樣，v8.6、v8.7 都會）。

**修改**：
- 畫中心線途中按「平移」：不結束繪製，已點的點保留。改為暫時用**左鍵拖曳平移**，游標變成手形，狀態列會提示。
- 再按一次「平移」，或按「繪中心線」，就回到繼續點選。
- 平移中雙擊不會結束繪製。Esc 一樣是取消繪製。
- 滑鼠中鍵拖曳、滾輪縮放照舊可以隨時用。
- 原本提議的「空白鍵＋拖曳」沒有做。空白鍵已經是「尋找地形（回到地形主區）」的快捷鍵，改掉會打亂原本的操作。

## 二、平面工具列調整

- **繪線鎖點常駐工具列**：鎖點開關、端點、中點、長度吸附，現在都在平面上方工具列，不再收進「⋯ 更多」。
- **補高程點、翻網格、尋找地形、純折線**移回左側「平面工具」卡片。
- 視窗較窄時，工具列按鈕由右往左縮成只剩圖示，滑鼠停留會顯示名稱。「平移」「繪中心線」最後才縮。仍然放不下時，按鈕才收進「更多」；鎖點設定一律留在工具列上。

## 三、護岸示意圖與圖例

- **護岸卡片**：型式選單下方新增**斷面示意小圖**，畫法和「新增護岸」精靈相同（結構體、示意地形、開挖線、尺寸代號）。換型式或改尺寸時會跟著更新。
- 下拉選單本身是瀏覽器內建元件，只能顯示文字，所以圖放在選單下方。
- **平面圖例（🎨 圖例）**新增三列：護岸水側趾線／岸頂線（白實線）、護岸背側線（白虛線）、選取中的護岸（青框）。圖例預設仍是收起，按右上「🎨 圖例」開啟。

## 四、結構物名冊（型錄）縮圖重畫

**有原工具圖的 11 種，縮圖改取原圖主要視圖**。做法是關閉尺寸、文字圖層後裁切，再轉成淺色底：

| 型錄項目 | 取用原圖視圖 |
|---|---|
| 透過性鋼格框潛壩 | 正面圖（H 型鋼格框） |
| 攔石工（H 型鋼＋疏伐木） | 正面圖（整排 H 型鋼與疏伐木） |
| 階梯式固床工 | 縱斷面（階梯、植筋、漿排塊石） |
| 橫向截水溝＋TGB 格柵板 | 平面圖（格柵板、集水井） |
| 植生塊（RC 箱）護岸 | 斷面（分層疊砌 RC 箱、L 型基礎） |
| 級配複式斷面鋪設路面 | 平面圖（RC 車轍帶、中央級配） |
| RC 路面 | 斷面（焊接鋼線網） |
| 固床工＋80φ 基樁 | 正面圖（基樁） |
| 梳子壩 | 正面圖（梳齒墩） |
| 護坡基礎補強 | 平面圖（RC 格框、格室塊石） |
| 生物通道 | 開口式動物通道剖面（爬梯） |

**其他型式**：
- 縮圖改挑最能辨認的視圖：場鑄箱涵、#1 固床工、預鑄拱型、格框式固床工用正面圖，曲型副壩用平面圖。
- 縮圖加上材料填色：混凝土灰、塊石橘、排水溝青。

**原本沒有縮圖的「生物通道」「護坡基礎補強」已補上**。

**待建置型式**（例如擋土牆）改顯示依名稱分類的灰色通用示意，並標「待建置（通用示意）」，不再整片空白。只列成小標籤的待建置名稱維持原樣；這些型式還沒有計算程式。

**說明**：原圖縮圖取自原工具的畫面，比例、線型與原圖一致。尺寸與文字已關閉，但仍有少數引線殘留，例如梳子壩的尺寸線。
