# 位置圖底圖在 AutoCAD 顯示：K1、K2、K4（併入 v8.4）

基準：v8.3。只改 `pkgmod.js`、`r2kmod.js` 和測試 `p10_emap.js`；`lymod.js`、`patch.py` 都沒動。

- **K1** `r2kDoc` 只在有影像時加 CLASSES 區段：放在 HEADER 和 TABLES 之間，宣告 IMAGE、IMAGEDEF、IMAGEDEF_REACTOR、RASTERVARIABLES（ISM）。v7.7 少了這段，AutoCAD 只顯示外框加 X。其他 DXF 沒有影像，不加這段，全圖 DXF 長度不變。
- **K2** 出圖包多一個 `DZ-02_LOC_EMAP.scr`。開位置圖 DXF 後，輸入 `SCRIPT` 選它，或把它拖進 AutoCAD 視窗，就會：
  - 切到模型空間，建 LOC_MAP 圖層。
  - 用 `-IMAGE` 依 TWD97 插入點、寬度和旋轉角貼上底圖。路徑取 DWGPREFIX，也就是 DXF 所在的資料夾。
  - 把底圖移到最後面，再 ZOOM E。
- **K4** 出圖說明附手動插入數值：IMAGEATTACH 的插入點 X、Y，比例（寬度）和旋轉。
- 測試：`p10_emap.js` 加檢查 CLASSES（只在位置圖和合併檔）、指令稿內容、手動數值。42 支回歸測試全過。
- ezdxf 讀檔：位置圖和合併檔都讀到這四個類別，audit 0 錯。AutoCAD 實際顯示要請使用者確認。
