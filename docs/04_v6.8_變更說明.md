# 砥柱 DiZhu v6.8 變更說明（中心線鎖點、插入 IP）

基準：v6.7 交接包（含護岸 thread 的 rvmod.js）。只新增 tcv4/ipxmod.js，patch.py 第 19 行尾端串接 ipxmod.js、第 504–505 行版本字樣改 v6.8。

## 1. 鎖點設定移到「平面工具」卡片
- 「繪中心線」下方新增一列：🧲 鎖點（總開關，快捷鍵 F3）、□ 端點、△ 中點、長度吸附（不吸附／0.5／1 m）。
- 原中心線卡片的「繪線鎖點」勾選與「中心線定線」卡片的長度吸附，移到這一列（不再兩處）。
- 按住 Alt 暫時不鎖點、Shift 不做長度吸附，與以前相同。設定存在專案檔（snapCfg）；舊專案預設端點、中點都開。

## 2. 中點鎖點
- 中點來源：DXF 線每段、中心線每段（含正在繪製的）、整治區（含封閉邊）、基準線、擋土牆、暫存線。
- 游標 10 px 內取最近的點；畫面標示「端點」（洋紅 □）或「中點」（青 △）。整治區、基準線等點繪工具也適用。

## 3. 插入 IP
- 「➕ 插入 IP」：移到中心線上顯示黃色預覽（插入位置、距前後點、里程），點一下插入，可連續插入；Esc 結束。
- 平移／改 IP 模式下 Shift＋點中心線也可插入。
- IP 表（雙擊圖上 IP 表開啟）每列加「＋」：在該點與下一點的中點插入。
- 新 IP 落在原直線上，里程、結構物位置不變；半徑取「新 IP 預設 R」，偏角為 0 時沒有曲線。若插在相鄰曲線的切線長範圍內，狀態列會提醒該曲線會被縮短。
- 可用復原（Ctrl＋Z）取消。

## 4. 由 EP 接續延長
- 「➡ 由 EP 接續延長」：保留原 BP～EP，從 EP 繼續點選；Backspace 只退回新增的點；Esc 取消（原線不變）。
- 結束後原 IP 與里程不變，原 EP 變成 IP（半徑取預設 R）；縱斷面只把末端 VIP 移到新 EP 並貼合地面，BP 端不動。

## 驗證

- u.tcproj 全圖 DXF 長度 9556618，與 v6.7 相同。
