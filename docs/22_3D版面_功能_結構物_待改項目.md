# 砥柱 DiZhu 3D 視圖：版面、功能、結構物　待改項目（請勾選）

基底：v8.1（調查日 2026-11-07，尚未改任何程式）。

## 現況（v8.1 實測，載入 u.tcproj）
- 3D 畫面只畫三樣東西：TIN 地形、中心線（黃線）、水力檢核水面（hymod）。防砂壩、固床工、梳子壩、護岸、排水溝、整地、崩塌地、護坡補強等**全部沒畫**。
- 左側圖示欄只有一個「圖層」圖示，裡面是整頁平面圖層卡（含「2D 平面圖層顯示開關」等 3D 用不到的卡）；「3D 地形顯示」卡只有高程誇大倍率滑桿。
- 縱斷、橫斷有的右側浮動控制列（放大、縮小、平移、全圖、前視角、復原）與左上視圖標題列，3D 都沒有。
- 操作只有「左鍵旋轉、滾輪縮放」，不能平移，縮放不以游標為中心。
- 繪圖方式：Canvas 2D「由遠到近」排序填三角形，沒有深度緩衝。只畫地形時看不出問題，但加入結構物後，壩體、護岸和地形三角形互相穿插時遮擋會錯（物件會忽隱忽現或浮在地面上）。

## L 版面（比照平面／縱斷／橫斷 H1～H3）
- [ ] L1 左側圖示欄拆成 3D 專用圖示：「顯示」（高程倍率、物件開關與顏色、地表配色）、「視角」（預設視角、相機）、「圖層」（只留底圖、DEM、TIN 三張 3D 有用的卡，2D 圖層開關卡在 3D 隱藏）、「水力」（水面顯示）。點法同平面：點圖示切換、再點收合。
- [ ] L2 右側浮動控制列比照縱橫斷：放大、縮小、平移、全圖、前視角、復原。
- [ ] L3 左上視圖標題列「3D 地形模擬」＋操作說明按鈕，比照縱斷面。
- [ ] L4 圖例：右下角列出目前顯示的物件顏色（地形、中心線、壩、護岸、水面…）。

## F 3D 功能
- [ ] F0 繪圖改用 WebGL（自寫，不引入外部函式庫，單檔仍可離線），有深度緩衝，遮擋正確、旋轉順；不支援 WebGL 的電腦自動退回現行畫法。**建議做**，S 類結構物要畫得對幾乎需要它。
- [ ] F1 平移（右鍵或中鍵拖曳）、以游標為中心縮放。
- [ ] F2 預設視角按鈕：俯視、等角、上游看下游、下游看上游、左岸看、右岸看。
- [ ] F3 地表配色：高程分色（現行）／單色／坡度分色；三角網格線開關；地表透明度滑桿（看埋入地下的基礎、基樁）。
- [ ] F4 設計後地形：以各橫斷面設計線（開挖、回填、整地後）沿樁號連成設計面；可切「原地形／設計後／兩者」，兩者時挖方區紅、填方區綠。
- [ ] F5 點選查詢：點地面或物件，顯示 E、N、高程、樁號、物件名稱；點結構物可跳到它的卡片。
- [ ] F6 樁號標籤與橫斷面位置線（每 20 m 或依加樁），開關可選。
- [ ] F7 匯出目前 3D 畫面 PNG（簡報、報告用，可選 2 倍解析度）。
- [ ] F8 沿中心線漫遊動畫（由上游飛到下游）／自動環繞。（選做）
- [ ] F9 匯出 3D 模型 DXF（3DFACE，AutoCAD／Civil 3D 可開）或 OBJ（SketchUp 可開）。（選做）

## S 3D 中增加的結構物（每類都有顯示開關，數量計算不受影響）
- [ ] S1 防砂壩、副壩、固床工（標準圖型式）：壩體依現有斷面圖外框沿壩軸擠出，含溢洪口、翼牆、護坦；左右翼各自依參數。
- [ ] S2 梳子壩（壩體＋梳齒鋼管）、固床工＋基樁（基樁畫成圓柱，埋入部分在地表半透明時看得到）。
- [ ] S3 護岸：依每個橫斷面上的護岸斷面外框，沿樁號連成牆體（各型式共用，含左右岸、起訖樁號）。
- [ ] S4 護坡基礎補強：格樑與填石範圍。
- [ ] S5 排水溝：溝體沿路線擠出。
- [ ] S6 整地範圍、崩塌地整治區（含擋土牆）、自由梁護坡、生物通道。

- 完整：全部（F8、F9 可後做）。
