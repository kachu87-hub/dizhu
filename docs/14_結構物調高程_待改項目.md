# 結構物在縱橫斷面調高低：調查與待改項目（請勾選）

基準：v7.5。尚未改程式。

## 調查結果（v7.5 實測，u.tcproj 固床工1 @0K+220.25）
- 功能其實存在：stmod.js「拖曳控點（縱斷面／橫斷面）」。
  - 縱斷面：結構物上有兩個 ◆（洋紅＝壩底 zB、黃＝溢洪口底／頂 zS），可上下拖曳，每 0.05 m 一格。實測拖曳後壩底 677.76 → 679.40。
  - 橫斷面：◆ 控點附「壩底／溢洪口底／h1／左右翼頂」標籤，可拖曳。實測可用。
  - 數值：結構物卡「① 高程」有「整座壩底部高程 zB」輸入框。
- 為什麼找不到／用不了：
  1. 縱斷面自 v7.0 預設固定比例 X 1:500／Y 1:200，按「全圖」只回到起點附近；結構物（0K+220）在畫面右側外面，要自己平移過去才看得到 ◆。
  2. 縱斷面的 ◆ 很小、沒有文字標籤，游標移上去才變成上下箭頭，不易發現。
  3. 橫斷面只有「單一樁號精細放大圖」才畫控點；預設的「全線斷面矩陣總覽」沒有控點。
  4. 勾「連動設計線」（預設）時，拖曳或輸入高程會連設計線一起移動（在壩址的變坡點升降），看起來像整條線在動；取消勾選才只動結構物本身（縱斷面落差改成手動）。

## 待改項目
- [ ] **S1 結構物卡加「高程微調」列**：壩底 zB、頂（溢洪口底）zS 兩個數值框，旁邊 ▲ ▼（每次 0.05 m，Shift 0.5 m）；連動狀態用文字提示「設計線會跟著動」。
- [ ] **S2 縱斷面控點加標籤、放大**：◆ 放大、旁邊標「壩底 EL xxx.xx」「頂 EL xxx.xx」（同橫斷面），滑過時狀態列提示「上下拖曳調整高程」。
- [ ] **S3 縱斷面「全圖」與「跳到結構物」**：固定比例時「全圖」改為顯示整條縱斷面（或保留比例但置中選取的結構物）；結構物卡清單點一下＝縱斷面平移到該結構物。
- [ ] **S4 橫斷面矩陣也能調**：矩陣總覽中點結構物所在的格子，自動切到單一放大圖並顯示控點；或矩陣格子內也畫控點。
- [ ] **S5 鍵盤微調**：在縱／橫斷面選取結構物後，↑ ↓ 每次 0.05 m（Shift 0.5 m）調壩底高程，Esc 取消選取。

## 2026-11-07 使用者回報（截圖）：拖「◆頂」固床工就加高，要的是設計高程移動
- 原因：「◆頂」(zS) 的設計是改高度 h2；整座移動要拖「◆底」(zB)，但它標在結構物右側很遠處。
- [ ] **T1** 拖「◆頂」改為整座上下移動（h2 不變，連動時設計線跟著動）；按住 Shift 拖才改高度。
- [ ] **T2** 拖曳時游標旁即時顯示「頂 EL a → b（整座移動）」或「h2 a → b（改高度）」。
- [ ] **T3** 「◆底」移回結構物正下方。
- 縱斷面◆同規則。

## 2026-11-07 補充：箱籠固床工（sltmod g604）
- 「◆頂」「◆底」在箱籠固床工都被 v5.8 設計成「增減箱籠層數」（sltmod.js 檔尾 stApplyDrag 覆寫），所以拉底也是加高。
- 目前能整座移動的只有結構物卡「整座壩底部高程 zB」輸入框（實測 +0.5 m：層數、h2 不變，上下游設計高同升 0.5 m）。
- T1 擴及箱籠固床工：拖◆（頂或底）＝整座移動、設計線跟著動；Shift＋拖頂＝增減層數。

## 2026-11-07 全型式實測（v7.5，u.tcproj，拖曳 +0.5 m，連動設計線）
| 型式 | 拖◆頂 | 拖◆底 |
|---|---|---|
| 防砂壩、副壩、一般固床工 | 改高度 h2（+0.49），設計線不動 | 整座移動（+0.49），上游設計高同步 |
| 箱籠固床工 | 增減箱籠層數 | 也是增減箱籠層數 |
| 石樑、嵌石、預鑄拱型、踏步式、場鑄箱涵、梳子壩、#1、格框式（原圖移植 8 種） | **只改外包高度 h2，結構物本體與數量不變 → 外包與實體不一致（bug）**，例：石樑實體 0.35 m、外包變 0.84 m | 整座移動，正常 |
