# 砥柱 DiZhu v7.6 變更說明：結構物調高程（S1～S5、T1～T5）

以 v7.5 為基底。新增模組 `stzmod.js`（接在 uimod.js 之後），並小改 `stmod.js`（控點外觀與橫斷 ◆底 位置）、`patch.py`（版本字串、縱斷 profileView 加 padB）。

## 操作方式（給使用者）

| 想做的事 | 怎麼操作 |
|---|---|
| 整座結構物上下移動（設計高程） | 縱斷或橫斷面拖 **◆頂** 或 **◆底**；高度 h2 不變。勾「連動設計線」時，設計線會跟著動 |
| 改結構物高度 | **Shift＋拖 ◆頂**。防砂壩、副壩、一般固床工改 h2；箱籠固床工改層數 |
| 用鍵盤微調 | 點一下結構物的 ◆ 控點，或在卡片清單點選它，再按 **↑↓**，每次 0.05 m，按住 Shift 為 0.5 m。停手約 0.4 秒後才重算設計線。按 Esc 取消選取 |
| 直接輸入高程 | 卡片「① 高程」新增 **整座頂 EL** 欄位和 ▲▼ 按鈕，每次 0.05 m，按住 Shift 為 0.5 m。旁邊會提示「設計線會跟著動」或「只動結構物」 |
| 找到結構物 | 固定比例的縱斷面按「全圖」，整條縱斷都會縮進畫面。在卡片清單點結構物時，縱斷會平移到它的位置，橫斷會切到單一圖 |
| 橫斷矩陣 | 點到有結構物的格子，會直接切到單一橫斷面，控點才會出現 |

拖曳時，游標旁會顯示目前的變化，例如「頂 EL 682.51 → 682.91（整座移動・設計線跟著動）」、「h2 1.50 → 2.00（改高度）」或「層數 3 → 4」。滑鼠移到控點上時，狀態列會說明這個控點怎麼用。

## 各項

- **T1**：所有型式的結構物，拖 ◆頂 或 ◆底 都是整座上下移動，以拖曳起點為基準，取 0.05 m 的整數倍。舊版箱籠固床工拖曳時會改層數，現在只有 Shift＋拖 ◆頂 才改層數。
- **T2**：拖曳時游標旁顯示浮動提示。
- **T3**：橫斷面的 ◆底 移回結構物中心線正下方，標籤放在左邊。
- **T4**：Shift＋拖 ◆頂 改高度。8 個移植型式（石樑、嵌石、預鑄拱型、踏步式、場鑄箱涵、梳子壩、#1、格框式）的高度由型式參數決定，不能拖。拖曳時游標旁和狀態列會提示到卡片的型式參數修改。
- **T5**：每次重算前，8 個移植型式的外包 h2 都會依型式參數重算（sltSync）。舊版拖錯而存下錯誤 h2 的專案，打開後會自動恢復正確值。例如石樑固床工被拖成 0.84，重算後回到 0.35。
- **S1**：卡片新增頂高程輸入、▲▼ 按鈕和連動提示。附屬結構物的高程跟隨主壩，所以不顯示這一列。
- **S2**：控點放大，並加上「頂 EL …」「底 EL …」標籤（深色底），滑過控點時狀態列有提示。
- **S3**：固定比例模式的縱斷面「全圖」改為縮放到整條縱斷可見。原本是回到 1:1，只看得到起點。在清單點選結構物時，縱斷平移到結構物，橫斷矩陣切到單一圖。
- **S4**：在橫斷矩陣點到有結構物的格子，會切到單一圖。
- **S5**：↑↓ 鍵微調。點 ◆頂／◆底 後，游標不會停在 zB 或 h2 欄位，以免 ↑↓ 變成改欄位數值。在圖面空白處點一下，或按 Esc，就會取消選取。

## 已知狀況

- 連動模式下，整座移動後的高程由設計線反推，可能和輸入值差 1～3 mm。這是 v7.5 原本就有的行為，例如輸入 +0.50，實得 +0.499。卡片顯示到 0.01 m，看不出差異。
- 箱籠固床工 Shift＋拖 改層數，要拖過半層高度才會變。這和舊版的規則相同。

## 測試

- 原有 35 支測試全部通過，另新增 `tests/p12_stz.js`，共 36 支。
- p12_stz 逐一測試 11 種結構物型式的拖 ◆頂、拖 ◆底 和 Shift 拖，再測試 T5 復原、S1 輸入和 ▲▼、縱斷面實際滑鼠拖曳、Shift 拖、↑↓ 和 Esc、固定比例全圖、清單平移，以及矩陣切單一圖。
- 全圖 DXF 長度維持 9556658，與 v7.5 相同。
