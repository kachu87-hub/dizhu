# 砥柱 DiZhu v7.0 變更說明（出圖排版依案例）

基準：v6.9。依據：安區122林班第二期治理工程圖說（`dizhu/ref/`）。06 待改項目 A～G 全部完成，C5 採 (a)（數量表留在最後一張）。

## 一、縱斷面預設（A）
- 新專案縱斷面比例預設 **X 1/500、Y 1/200**，可自行再改。
- 「左／右護岸頂線」「左／右基礎底線」預設**不勾**；下部資料框「左側高／右側高」預設**不勾**。
- 只影響新專案，舊專案檔載入後維持原設定。

## 二、圖框與標題欄（B）
- A3 橫式，外框＋內框雙線，內框底部標題欄（13.5 mm、三列），欄位依案例：機構名稱｜主管／技師／校核｜設計／繪圖／日期｜工程名稱、圖名、比例尺（平面類多「單位」格）｜設計單位公司章｜設計單位｜技師執業圖記｜圖序／圖號。
- 出圖包對話框新增：**機構名稱、工程名稱、設計單位**，以及主管、技師、校核、設計、繪圖人名（選填），全部隨專案存檔。
- 比例尺寫「1/500」；縱斷面寫兩行「X=1/500」「Y=1/200」。
- 圖號＝**n/N**（第幾張／總張數）。檔名與 R2000 配置名稱仍用「前綴＋序號」（預設 DZ-01…）。

## 三、排版順序與圖名（C）
順序：一般說明及圖目錄 → 位置圖 → 全區平面配置圖 → 平面詳圖(1/n) → 縱斷面圖(1/n) → 橫斷面詳圖(1/n) → 各工項詳圖 → 結構物數量表（最後）。
- 圖名依主題（例「平面詳圖(2/3)」「橫斷面詳圖(5/39)」「左岸護岸1 重力式混凝土護岸詳圖」），多中心線時加「－段名」。
- **封面**：大字機構＋工程名稱，左半「特別說明／一般說明」（對話框可編輯，預設帶常用條文），右半兩欄圖目錄表（圖號｜圖名），右下「環境生態保護特別說明」（可關閉）；圖目錄放不下時自動加頁。
- **位置圖**：空白圖框，模型空間座標＝TWD97，框內標「工程位置」與「GPS 座標（TWD97）X, Y」，附指北針、比例尺條；地形圖依座標插入即自動對位。比例預設 1/10000（可改）。
- **平面詳圖**：沿中心線依 1/500（可改）分張，北朝上，畫相鄰張範圍虛線與「接續第 n 張」。

## 四、全區平面配置圖（D）
- 左欄：工程內容（由數量自動帶出，可改）、圖例、控制點座標及高程表、IP 資料曲線表（IPNO／I／R／D／TL／CL／SL／BC／MC／EC）。
- 右上指北針＋比例尺條；比例自動取（可在對話框固定）。

## 五、縱斷面圖（E）
- 比例固定 X/Y，放不下 A3 時**分更多張**，不再縮比例。
- 左側高程尺、DATUM ELEV、各樁號垂直線（不畫滿版格線）。
- 下方資料表依案例列序：溪床坡度（S=…%、L=…m）／構造物總高／挖填／構造物頂高／計畫溪床高／原地形高／構造物基礎高／單距／樁號／曲線。
- 線別以一組引線標示（計畫岸頂高、原地形高、計畫溪床高、計畫基礎高），護岸起訖點以引線＋文字標註；去掉圖內上方說明列。

## 六、橫斷面詳圖（F）
- 一張排多個斷面，由下而上樁號遞增；太大的斷面單獨一張並放大比例（標題欄出現警示）。
- 每斷面下方樁號（雙底線），右側「挖方／填方 m3」（與土方計算表相同，平均斷面法）。
- 尺寸標註（cm）：溪寬總寬與分段寬、護岸高、基礎寬、基礎深；CL 符號。
- 護岸以引線標註型式名稱，起訖斷面加說明。
- 版型可選：無格線（預設）／帶高程距離格線＋圖例。

## 七、字型、線條（G）
- 字型 **CHT＝romans.shx＋大字體 chineset.shx**（$DWGCODEPAGE＝ANSI_950），對話框可改回標楷體 kaiu.ttf。
- 紙上字高：標題 7 mm、樁號 5 mm、一般標註 2.5～3 mm、標題欄 2.4 mm（機構名稱 3.5 mm）。
- 出圖包一律黑白（顏色 7），以 R2000 圖層線寬區分：圖框 0.5、設計線／結構物／護岸 0.35、地面線 0.18、尺寸／文字 0.13 mm。畫面上的彩色顯示不變。
