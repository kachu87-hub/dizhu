# 砥柱 DiZhu v6.9 變更說明（橫斷面偏角、護岸依樁號編號）

基準：v6.8 交接包。新增 tcv4/secrotmod.js（串在 ipxmod.js 之後）；改 rvmod.js 第 58–65 行（rvNo／rvName／rvShort）；patch.py 版本字樣改 v6.9，檔尾加 v6.9 的 rep（斷面法線、平面斷面線顏色、斷面標題斜交標註）。

## 1. 單獨調整特定樁號的橫斷面方向
- 左側「橫斷面編輯」卡，讀取長度下方新增「斷面偏角 θ (°)」、「↻ 平面點選方向」、「偏角歸零」。
- θ＝0 為垂直中心線（預設）；平面上逆時針為正；上限 ±60°；清空＝回到垂直。
- 中心線與樁號都不動，斷面線以它和中心線的交點為軸旋轉。
- 「↻ 平面點選方向」：切到平面圖（斷面不在畫面內會自動置中放大），灰虛線＝垂直方向，橘線＝游標決定的新方向；點一下設定；可用鎖點（F3）對準岸邊特徵點；Esc 結束。
- 偏過的斷面：地形取樣、平面斷面線（橘色）、DXF CROSS_STATIONS、斷面圖（畫面與 DXF）標題「斜交 +θ°」都依新方向。斷面上的偏距沿斜線量，河寬、護岸照原參數畫；土方仍用平均斷面法、間距用中心線樁距。
- 防砂壩（結構物）所在樁號不套用偏角（輸入框停用）。
- 偏過的斷面線在讀取範圍內與相鄰斷面交叉時，狀態列與卡片顯示「⚠ 斷面交叉」。
- 存在 state.secExt[樁號].rot（同樁號的上／下斷面共用），隨專案檔、復原（Ctrl＋Z）、多中心線一起保存。改中心線讓樁號值改變時，該斷面偏角會失效（與讀取長度相同）。
- 平面圖上的護岸、排水溝位置仍依中心線垂直偏距；偏角大時斷面圖與平面圖約差 1/cosθ（15° 約 3.5%）。

## 2. 護岸依起點樁號自動編號
- 同一岸的護岸依起點樁號排序編號（起點相同比終點，再比新增順序）；中間插入護岸時號碼自動重排（右護1、2、3、4）。
- 只改顯示名稱（卡片、平面標籤、報表、檢核、DXF 都用 rvName／rvShort），不重排 state.revs，選取與資料不受影響。
- 舊專案若曾中間插入護岸，開啟後號碼會改成依樁號順序。
