# 縱斷面、橫斷面版面比照平面圖：待改項目（2026-11-06，基底 v7.5）

## 現況（v7.5）
- 平面視圖：左側圖示欄有 7 個圖示（匯入、平面、圖層、結構物、崩塌地、排水、水力），點圖示切換面板。
- 縱斷、橫斷視圖：圖示欄只剩一個「縱橫斷面」圖示，真正的功能是面板頂端一排文字按鈕（縱斷：縱坡設計、圖面資料框、樁號表、結構物、護岸、整地；橫斷：斷面編輯、樁號表、結構物、護岸、整地），外加 ⊞ ⊟ 兩顆。按鈕擠成一排、沒有圖示，和平面視圖操作方式不同。
- 平面視圖的「結構物」圖示點進去，也還有一排文字按鈕（結構物、護岸、整地）。

## 待改項目（請勾選）

- [ ] **H1. 縱斷、橫斷的子頁籤搬進左側圖示欄**
  每個子頁籤變成一個圖示（縱坡設計、圖面資料框、樁號表、斷面編輯、結構物、護岸、整地各配一個線條圖示），切到哪個視圖就顯示該視圖用得到的那幾個。面板頂端那排文字按鈕拿掉，⊞ ⊟（全部展開／收合）移到面板右上角變成小圖示。再點一次目前圖示＝收合面板，和平面視圖一樣。
  影響：左側圖示欄、面板頂端子頁籤列。卡片本身和分組不動，earthShowGroup 等程式照用。風險：低到中。

- [ ] **H2. 平面視圖的「結構物」也拆成三個圖示**
  平面視圖圖示欄由 7 個變 9 個：匯入、平面、圖層、結構物、護岸、整地、崩塌地、排水、水力，面板內不再有那排文字按鈕。
  影響：同 H1。風險：低。缺點是圖示欄變長，1366×768 螢幕在 1.15× 倍率下約可放 9～10 個，剛好放得下。

- [ ] **H3. 面板頂端加標題列**
  內容面板最上方顯示目前功能名稱（例如「護岸」），右邊放 ⊞ ⊟ 和「收合 ◀」，三個視圖一致。
  影響：只加一列標題。風險：低。

- [ ] **H4. 頂部列按鈕加圖示**
  4 大視圖、開啟 DXF、另存專案、載入、檢核、匯出、設定都加同一套線條圖示（v6.x 時曾統一把表情符號拿掉，這次改用和左側一致的單色線條圖示）。
  影響：頂部按鈕外觀。風險：低。

- [ ] **H5. 縱斷、橫斷畫布上方的浮動列改成和平面一致的外觀**
  目前橫斷面浮動列在 1366 寬會排成兩排並蓋到第一張斷面。改成單排膠囊樣式、按鈕加圖示，放不下的收進「更多 ▾」。
  影響：縱、橫斷浮動列（crossFloatingBar、profileFloatingBar）。風險：中低，裡面的下拉選單與輸入欄 id 不變。

## 建議
先做 H1＋H2＋H3（三個視圖的左側操作方式完全一致），H4、H5 看你要不要一起做。

## 其他
