# 位置圖底圖沒顯示、橫斷面字太大：原因與修法（待勾選）

基準：v7.5（出圖部分的 lymod.js、pkgmod.js、r2kmod.js 和 v7.2 相同）。程式還沒動。

## 一、位置圖為什麼是「空白圖框加一個大 X」

截圖裡的大 X 是 AutoCAD 的「找不到影像檔」顯示，不是沒抓到地圖。
- 程式只有在地圖成功下載後，才會寫入影像參考。
- 左下角那行小字是「底圖：內政部國土測繪中心…」，也表示下載成功。

問題出在 AutoCAD 找不到 LOC_EMAP.png。可能的原因：

1. **直接在 zip 裡雙擊開 DXF。** 這時 Windows 只把 DXF 解到暫存資料夾，png 沒有跟著解出來。
2. **DXF 記的是純檔名「LOC_EMAP.png」。** 有些 AutoCAD 版本不會到圖檔所在資料夾找，要寫成相對路徑「.\LOC_EMAP.png」才會。
3. **只把 DXF 複製到別的資料夾，png 沒有一起帶過去。**

**現在就可以試的救法：**
1. 先把 zip 全部解壓縮到同一個資料夾，再從那個資料夾開 DXF。
2. 如果還是 X，輸入指令 `XREF`（外部參考），選 LOC_EMAP，「找到位置」改指到解出來的 LOC_EMAP.png。

## 二、修法（請勾選）

- [ ] **J1** DXF 裡的影像路徑改寫成相對路徑「.\LOC_EMAP.png」，並補上 AutoCAD 影像需要的 RASTERVARIABLES 物件。只要 png 和 DXF 在同一個資料夾就會自動找到。
- [ ] **J2** 影像檔名改成和位置圖 DXF 同名，例「DZ-02_位置圖.png」，一看就知道要放在一起。
- [ ] **J3** 另外輸出一份「位置圖_含底圖.pdf」（A3，地圖、圖框和標題欄都在同一個檔裡）。
  - 不必處理外部參考，可以直接列印或附在報告。
  - DXF 照舊附影像參考。
- [ ] **J4** 出圖說明和完成訊息加一句提醒：「請先把 zip 全部解壓縮，再開 DXF」。

DXF 規格本身不能把影像「內嵌」在檔案裡，只能外部參考；這是格式限制。要一個檔就看得到地圖，只有 J3 的 PDF。

## 三、橫斷面字太大

v7.2 依案例把樁號定為 6 mm、挖方填方 3.5 mm。您的斷面比較窄（溪寬約 20～30 m），在 1/300 下斷面本身只有約 8 公分寬，所以字顯得很大。

- [ ] **J5** 預設改小：樁號 4 mm（雙底線跟著縮）、挖方填方 2.5 mm。
- [ ] **J6** 出圖包對話框加「橫斷面字高」選項：小（樁號 3.5／挖填 2.2）、中（4／2.5，預設）、大（6／3.5，同案例）。

## 我的建議

J1、J2、J4、J5 一定要做，工作量小。J3（PDF）和 J6 看您需要。
