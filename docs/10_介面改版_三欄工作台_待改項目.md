## 二、實測還擠的地方（1920×1080 與 1366×768）

1. 頂部列在 1920 寬是 2 排（110 px），在 1366 寬是 3 排（161 px）。主因是介面倍率 1.4× 再加上「匯出 CSV、檢核、匯出 xlsx、匯出 DXF、出圖包、自動存檔」六顆並排。
2. 左側 7 個主頁籤是 4＋3 兩排大按鈕，光頁籤就佔 185 px 高；左側欄寬 476 px（340×1.4）。1366 寬時畫布只剩約 890×550。
3. 平面視圖畫布上同時有：左上資訊＋提示兩條、右上圖例、右側 6 顆視角鈕、左下雷達圖、右下「工作內容」表。1366 寬時圖例會蓋到右上角圖面，工作內容表和雷達圖佔掉下方四成。
4. 寬表格仍塞在左側窄欄：縱斷面里程樁號表（16 欄，最小寬 1330 px）、實測展點表、IP 要素表要左右捲。IP 表已另有底部編輯器（#ipEditor），但它的左邊界寫死 360 px，和現在 476 px 的側欄對不齊。

## 三、待改項目（請勾選）

每項都可以單獨做。做法一律是新增一個版面模組（暫名 uimod.js，串在 patch.py 最後），只搬 HTML 容器和改 CSS，不動計算、DXF、數量。

- [ ] **A. 頂部列單行化**
  左：Logo＋中心線（主流/支流）；中：4 大視圖；右：「📂 開啟」「💾 儲存」兩顆主鈕＋「匯出 ▾」下拉（CSV、數量表 xlsx、DXF、出圖包）＋檢核徽章＋「⚙」下拉（介面／圖面倍率、自動存檔）。
  影響：頂部 HTML 與按鈕位置。風險：低。功能不變，只是少數按鈕要多點一下下拉。

- [ ] **B. 左側改成「窄 Icon 欄（52 px）＋內容面板」**
  7 個主頁籤改成最左側一條直排圖示（滑過顯示名稱），右邊是內容面板；再點一次目前的圖示，面板收合、畫布全寬。面板寬度改為可拖拉，記住上次寬度。
  影響：側欄、畫布寬度計算、雷達圖與 IP 編輯器的左邊界。風險：中。要一起修掉 #ipEditor 寫死 360 px 的問題，並檢查收合後畫布重算大小。

- [ ] **C. 畫布上方情境浮動工具列**
  把左側「平面工具」卡片的按鈕搬到畫布正上方的膠囊工具列，只在平面視圖出現；縱斷、橫斷沿用現有浮動列，但改成同一位置、同一外觀。
  影響：平面工具卡（v6.8 的 IP 插點列、v7.1 的加樁鈕都掛在這裡）。風險：中。這些模組是找 planToolsGroup 塞按鈕，要確認搬家後都還在。

- [ ] **D. 「結構物」主頁籤只放結構物**
  左側主圖示拆成「縱橫斷面」（斷面編輯、縱坡設計、圖面資料框、樁號表）與「結構物」（防砂壩/副壩/固床工、護岸、整地）兩個。做法是讓圖示直接切到對應的子頁籤組，不搬卡片本身。
  影響：左側頁籤對應表。風險：中低。卡片 DOM 不動，其他模組用 switchSideTab('tab-earth') 跳轉的地方照常可用。

- [ ] **E. 底部可收合資料抽屜**
  畫布下方加一個全寬抽屜（有頁籤、可拖拉高度、可收合），把「縱斷面里程樁號表」「實測展點表」「IP 要素表」搬進去；現有的 #ipEditor 併成其中一頁。抽屜打開時畫布自動縮短，不會蓋住圖。
  影響：三張表的容器位置。風險：中高。表格本身與點列跳轉邏輯不動（id 保留），但「改善橫斷面編輯與加樁管理」那邊正在改樁號表，兩邊都會碰到這張表。
  備註：提案裡的「結構物數量明細表」目前在畫面上沒有獨立表格（只在結構物卡的「數量計算」和 xlsx 裡）。若要放進抽屜，等於新做一張畫面表，建議另列。

- [ ] **F. 畫布角落整併**
  右上圖例改為一顆「🎨 圖例」按鈕（點開才展開）；左上資訊與提示兩條併入底部 COMMAND 狀態列；右下「工作內容」表與左下雷達圖加收合鈕，並記住收合狀態。
  影響：平面視圖的浮動區塊。風險：低。

- [ ] **G. 預設介面倍率依螢幕自動決定**
  現在固定 1.4×。改成依視窗寬度預設（例如 ≥1800 px 用 1.4×、1366 左右用 1.15×），使用者手動調過就記住手動值。
  影響：--ts 預設值。風險：低。

## 四、建議順序

建議第一版做 A＋B＋D＋F＋G（版面骨架，風險低到中），C 與 E 第二版再做。E 會和樁號表那邊的工作重疊，最好等那邊定案後再搬。
