# 砥柱 DiZhu v7.1 變更說明（平面圖斷面微調、加樁管理）

基準：v7.0 交接包（含 v7.0 出圖排版）。
新增 tcv4/xpmod.js（串在 patch.py 第 19 行尾端 lymod.js 之後）；patch.py 只改兩處：模組串接加 xpmod.js、版本字樣 v7.1。其他模組未改。

## 1. 在平面圖（介面 1）直接微調斷面方向（C1）
- 在平面圖點「樁號文字」或「斷面線」＝選取該樁，並開啟「斷面微調」視窗。
- 選取的斷面線兩端出現橘色圓點●：拖曳即改偏角 θ（拖的是方向，不必拖到端點；可用 F3 鎖點對準岸邊特徵點），放開才設定，Esc 取消。端點在畫面外時，圓點放在畫面內同一條線上。
- 鍵盤：← 逆時針 +0.5°、→ 順時針 −0.5°（加 Shift 為 0.1°）；連按會累積，停 0.45 秒後一次寫入（一次復原步）。↑ ↓ 換上一樁／下一樁（斷面不在畫面內會自動平移）。Esc 關閉視窗。
- 視窗內也有：偏角輸入框、↺ +0.5°、↻ −0.5°、歸零、◀ ▶ 換樁。
- 防砂壩（結構物）樁號照舊不套用偏角（不顯示圓點，輸入框停用）。

## 2. 平面圖上的斷面預覽（C2）
- 「斷面微調」視窗內即時顯示選取樁號的橫斷面（與介面 3 同一畫法：地形線、設計線、護岸、結構物、挖填面積、斜交標註）。θ、河寬、護岸等資料改變後自動重畫。
- 可拖曳標題列移動位置、選「小／中／大」，位置與大小記在瀏覽器（下次開啟沿用）。只在平面圖顯示，切到其他介面自動隱藏。
- 介面 3 左側「橫斷面編輯」卡偏角列下方新增「🔍 平面圖微調斷面（附斷面預覽）」按鈕。

## 3. 相鄰斷面顯示（A5）
- 視窗開啟時，前後相鄰樁號的斷面線以淡灰虛線顯示；與目前斷面交叉時改紅色實線，交點畫紅點並標「交叉 0K+xxx」。視窗下方同時列出全線交叉清單。

## 4. 加樁表（B1）
- 「自行加樁號」下方的「已加樁：…」改為表格：樁號（m，可直接改）、點名（可改）、「看」、「✕」刪除。
- 「看」：選取該樁；在平面圖時置中並開啟斷面微調視窗。
- 多中心線匯流點產生的加樁顯示為灰色唯讀。
- 「清空」加確認對話框，且不會清掉匯流樁；手動輸入「加入」若與既有樁號重疊會擋下。

## 5. 改樁號／刪除時資料一起處理（B2）
- 改樁號：該樁以樁號存的手動資料一起搬到新樁號：河寬／護岸控制值、讀取長度、偏角 θ、上下斷面、左右側高、地形線折點。
- 刪除：同一批資料一起清除。
- 原樁號若還有其他樁（例如剛好與等距樁同號），資料留在原樁號，狀態列會說明。
- 新樁號與既有樁號 0.01 m 內重疊時擋下；超出中心線範圍也擋下。
- 改樁號、改點名、刪除、拖曳都可 Ctrl＋Z（工具列「復原」）還原，資料一起回來。

## 6. 平面圖拖曳加樁（B4）
- 選取的樁若是自行加樁，中心點出現洋紅色◆：沿中心線拖曳改里程（游標顯示「舊樁號 → 新樁號」，可 F3 鎖點，重疊時變紅），放開即套用（同 B2 搬資料）；Esc 取消。
- 按 Delete 刪除選取的加樁（視窗內也有「✕ 刪加樁」）。

## 注意
- 本版只增加操作介面，不改計算與出圖；u.tcproj 未改動時全圖 DXF 長度 9556658，與 v7.0 相同。
- 改樁號時，護岸、排水溝等物件的起訖樁號不會跟著動（它們存的是里程數值）。
