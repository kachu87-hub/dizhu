# 砥柱 DiZhu v8.2 變更說明：3D 視圖改版（L1～L3、F0～F2、S1～S3）

基底：v8.1。新增一個模組 tcv4/v3dmod.js（串在 demnet 之後），patch.py 只改模組串接與版本字樣。計算、數量、DXF 都沒動（測試確認全圖 DXF 長度與 v8.1 相同）。

## F0 改用 WebGL 繪圖
- 3D 改用 WebGL 繪圖（自己寫的，沒有引入外部函式庫，單一 HTML 仍可離線使用）。有深度緩衝，壩體、護岸和地形互相穿插時遮擋正確，旋轉也比較順。
- 電腦不支援 WebGL 時，會自動退回原本的簡易繪圖，畫面右下角會註明。
- **順便修正**：原本的 3D 投影其實是從地面下方往上看，畫面左右鏡像。現在改為從上方往下看，「俯視」時北朝上、東朝右，與平面圖一致。右下角加了指北符號。

## F1 平移與縮放
- 左鍵拖曳＝旋轉；右鍵或中鍵拖曳（或 Shift＋左鍵）＝平移；右側「✋ 平移」開啟時左鍵＝平移。
- 滾輪以游標所在位置為中心縮放，可放大到 60 倍，看得到單座結構物的細部。
- F 鍵＝全圖（原本在 3D 按 F 會跳回平面圖，已修正）；Backspace＝回到前一個視角。

## F2 預設視角
- 左側「視角」頁有六個按鈕：俯視、等角、上游看下游、下游看上游、左岸看右岸、右岸看左岸。上下游方向依全線中點的地面坡降判斷，左右岸依面向下游的方向。
- 另有「全圖」「前視角」按鈕，也會顯示目前看向的方位角、俯角與縮放倍數。
- 上方標題列也放了俯視、等角、上游看下游三個常用按鈕。

## L1～L3 版面比照其他視圖
- L1 左側圖示欄在 3D 變成四個圖示：顯示、視角、圖層、水力。點法和其他視圖相同（再點目前圖示＝收合）。
  - 顯示：高程誇大倍率，以及物件開關（地形、三角網格線、中心線、結構物名稱、壩體／固床工、基樁、護岸、水力水面）。開關狀態會記在這台電腦的瀏覽器裡。
  - 圖層：「2D 平面圖層顯示開關」「國土測繪中心底圖」這兩張只跟平面圖有關的卡片在 3D 隱藏，回到平面圖會恢復。
- L2 右側浮動控制列（放大、縮小、平移、全圖、前視角、復原）在 3D 也會顯示。
- L3 左上標題列「🏔️ 3D 地形模擬」，加上「❔ 操作說明」按鈕。

## S1～S3 3D 中加畫的結構物
- S1 防砂壩、副壩、固床工：壩體依各型式的正視圖外形，搭配斷面圖在每個高程的上下游範圍做成實體。有齒牆、護坦、垂直壁、側牆的會一起畫。原圖沒有可用正視圖的型式（例如石樑、嵌石固床工），或圖上主體只畫底版時，改用結構物的外包尺寸（全長 w、出露高 h2、基礎深 h3、厚 d1）畫成方塊。
- S2 梳子壩畫出壩墩與開口；固床工＋基樁的基樁畫成圓柱，支數與數量表相同（範例 22 支）。
- S3 護岸：依每個橫斷面上的護岸斷面外框沿樁號連成牆體，材料分色（混凝土、砌石、級配、PC）。
- 各類都可在「顯示」頁開關，結構物名稱與樁號會標在壩頂上方。
- 水力水面改由 WebGL 畫成半透明，會被地形與結構物正確遮住；出水高不足的標記與圖例照舊。

## 已知限制
- 地形仍是原地面（三角網），還沒有畫開挖或回填後的地形（清單 F4）。所以護岸、基礎有一部分會埋在原地面下面。要看埋在地下的部分，可以在「顯示」頁暫時關掉地形。
- 箱涵（bcul）畫成實心方塊，沒有挖出內孔。
- 中心線與名稱標籤是疊在畫面最上層，不會被地形遮住（和 v8.1 相同）。
