# 轉到專案的步驟
1. claude.ai 左側選「專案」→「建立專案」，名稱例如「砥柱 DiZhu」。
2. 專案指示：把 00_專案指示_貼進專案.md 的內容整份貼進去。
3. 專案檔案：上傳本壓縮檔內的全部檔案（或上傳整個 zip）：DiZhu_v6.4.html、u.tcproj、01_待辦與建議清單.md、tcv4 資料夾、profile-cross-section 資料夾、tests 資料夾。若專案不收資料夾，就直接上傳 zip。
4. 在專案裡開新對話，第一句：「依專案資料繼續砥柱，先把 zip 解開並建置確認可用。」
5. 之後每個功能批次開一個新對話；要改程式時等我說「可以動」。
6. 說明書：https://claude.ai/artifact/NeYhYtvbwv6vrHU18oPWcR
