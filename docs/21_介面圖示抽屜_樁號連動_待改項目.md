# 介面（頂部圖示、浮動列、底部抽屜）＋改樁號連動：待改項目（2026-11-07，基底 v8.1）

兩項合成同一版出（3D 改版先出 v8.2，本案以 v8.2 為基底出 v8.3，需相容 v3dmod 對 uimod 的覆寫）。以下現況是實際開啟 v8.1、載入 u.tcproj，在 1920×1080 與 1366×768 量到的。

## 第一部分：介面

### 現況
- 頂部列在 1366 寬已是單排，但按鈕全是文字（1. 平面、2. 縱斷、開啟 DXF、另存專案、載入、檢核、匯出、設定），和左側圖示欄風格不一致。
- 橫斷面浮動列在 1366 寬排成兩排（約 90 px 高），蓋住第一張斷面的上緣。
- 縱斷面浮動列橫跨整個畫布寬，裡面只有標題和「操作說明」一顆鈕。
- 平面視圖沒有浮動工具列，平移、繪中心線、加樁、放結構物等按鈕收在左側「平面工具」卡片裡（預設摺疊）。
- 寬表格仍塞在左側窄面板：縱斷面里程樁號表（16 欄）、實測展點表；IP 要素表另有「完整編輯」浮出視窗。
- 右下「工作內容」浮框（列出各物件起訖樁號）在 1366 寬會蓋住圖面約四分之一。

### 待改項目（請勾選）
- [ ] **U1. 頂部按鈕加圖示（H4）**：4 個視圖、中心線、開啟 DXF、另存專案、載入、檢核、匯出、設定，都加上和左側同一套單色線條圖示。視窗寬度不夠時自動只顯示圖示，滑過顯示名稱。風險：低。
- [ ] **U2. 縱斷、橫斷浮動列改單排膠囊（H5）**：橫斷面改單排，按鈕加圖示，放不下的收進「更多 ▾」；縱斷面那條縮成左上角小膠囊，不再橫跨整個畫布。裡面的下拉、輸入欄 id 不變。風險：中低。
- [ ] **U3. 平面視圖也加膠囊工具列（原 C 項，選做）**：把「平面工具」卡片的按鈕搬到畫布正上方，三個視圖的工具列同一位置、同一外觀。風險：中（v6.8 IP 插點、v7.1 加樁鈕都掛在這張卡，要逐一確認搬家後還能用）。
- [ ] **U4. 底部資料抽屜（原 E 項）**：畫布下方加全寬抽屜，有頁籤、可拖拉高度、可收合並記住狀態；抽屜打開時畫布自動縮短，不蓋圖。頁籤：樁號表（縱斷面里程樁號表）、實測展點表、IP 要素表（併入現在的「完整編輯」視窗）。左側「樁號表」圖示改成打開抽屜的樁號表頁。表格內容與點列跳轉不動。風險：中高。
- [ ] **U5. 抽屜加「物件清單」頁（選做）**：右下「工作內容」浮框改成抽屜的一頁，列出全部結構物、護岸、排水溝、整地、護坡基礎補強的起訖樁號，可直接改樁號，點列就跳到該物件。和第二部分搭配使用。風險：中。

## 第二部分：改樁號時，護岸、排水溝起訖樁號跟著動

### 現況
護岸、排水溝（沿中心線型）、整地、護坡基礎補強、結構物都把位置存成「里程數字」，彼此沒有關聯。所以下列四種情況，物件都留在原本的里程數字上，不會跟著動：

1. 移動加樁（v7.1 說明書寫的已知限制）：只有該樁的斷面手動資料會搬，起訖剛好設在這根加樁的護岸、排水溝不動。
2. 移動結構物：例如 u.tcproj 的右岸護岸 2 迄點 0K+220.25 正好接在固床工 1，固床工移走後護岸不會跟著縮放。
3. 改「起點樁號」：全線里程整體平移，但所有物件、加樁、縱斷面 VIP、各樁手動資料都還是舊數字，等於整批滑到別的位置。
4. 修改中心線（拖 IP、改 R、插入或刪除 IP）：同一個平面位置的里程變了，物件卻還是舊里程，所以在平面上會偏離原處。

### 待改項目（請勾選）
- [ ] **K1. 移動、刪除加樁時，接在加樁上的端點一起動**：起訖點在該加樁 0.01 m 內的護岸、排水溝（沿中心線型）、整地、護坡基礎補強端點，跟著移到新樁號。刪除加樁時端點留在原里程（不刪物件）。風險：低。
- [ ] **K2. 移動結構物時，接在結構物上的端點一起動**：改結構物樁號欄或在圖上拖曳時，起訖點在該結構物樁號 0.01 m 內的護岸、排水溝端點一起移動。風險：低。
- [ ] **K3. 改起點樁號時全部一起平移**：改起點樁號時跳出確認「一起平移／只改數字」。選一起平移：結構物、護岸（含加高、變寬、曲線控制點）、排水溝、整地（含分段與個別樁設定）、護坡基礎補強、梳子壩等、加樁、縱斷面 VIP、各樁手動資料（河寬、讀取長度、偏角、上下斷面、地面修正）全部加上差值。風險：中（以里程存的欄位多，要逐一列入並測試）。
- [ ] **K4. 修改中心線時，物件保持平面位置**：拖 IP、改 R、插入或刪除 IP 後，物件端點維持原本的平面座標，樁號依新中心線重新計算。縱斷面 VIP 和各樁手動資料維持里程不動。復原、讀檔、切換主流／支流時不觸發。設定裡可關閉。端點離新中心線太遠（例如刪掉該段）時不動並列出警告。風險：中高。

### 共通
- 每次連動都能 Ctrl＋Z 一次復原，狀態列列出哪些物件動了多少。
- 只對目前中心線上的物件作用；獨立基線型排水溝（自己畫的折線）不受影響。

## 建議
- 介面：U1＋U2＋U4。U3、U5 可這次一起做，也可下一版。
- 樁號：K1＋K2＋K3 一定要；K4 若您常在放好物件後才回頭修中心線，建議一起做。
- 測試：既有 39 支全部 noerr，另加 p14_ui（圖示、膠囊列不換行、抽屜開合與畫布高度）、p14_sta（K1–K4 各情境、復原、存讀檔）。
