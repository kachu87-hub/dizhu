# 砥柱 DiZhu v8.0 變更說明：整合梳子壩、固床工＋80φ基樁、護坡基礎補強

基底：v7.9（線上內政部 DEM 版）。依 15 號待改項目清單「照建議全做」（C1–C3、S1–S6 取 S5b、G1–G6、T1–T4），合併為同一版。

## 一、使用方式

| 結構物 | 在哪裡 | 怎麼放 |
|---|---|---|
| 梳子壩 | 結構物 → 固床工 → 型式選「梳子壩（直線型、N 座梳齒墩）」，或從結構物型錄「防砂設施」挑選 | 跟其他固床工型式一樣輸入樁號放置；「📏 依溪床寬設溢流段寬」會依該樁號溪床寬自動設左右溢流段寬 |
| 固床工＋80φ基樁 | 結構物 → 固床工 → 型式選「固床工＋80φ基樁（溢流口型）」，或型錄「固床工」 | 同上；「📏 依溪床寬設溢流口寬」設中央溢流口總寬 |
| 護坡基礎補強 | 縱橫斷面頁 → 護岸卡片下方「🧱 護坡基礎補強」（預設摺疊），或型錄「護坡」 | 按「＋左岸／＋右岸」，再設起訖樁號（可按「⟵斷面」取目前斷面樁號）；座數預設依區間自動，也可手動指定 |

## 二、各結構物做了什麼

### 梳子壩（S1–S6）
- 參數全部開放，預設＝原圖：墩數、墩寬、開口寬、左右溢流段寬、左右斜坡寬、左右翼牆寬（**左右可分開設**）、各層高度、坡比、前庭漿砌石槽、半橢圓護坦、鋼筋估算量 kg/m³。
- 各墩高度可逐座輸入（左→右，逗號分隔）。
- 數量改由圖面幾何計算：混凝土（含兩端斜退）、模板（依實際坡面長）、漿砌塊石（前庭石槽梯形＋半橢圓護坦）。
- 鋼筋：原圖鋼筋表是依預設尺寸配出的，改尺寸後無法逐支重算 → 以 **4.44 kg/m³** 估算（＝原圖鋼筋量÷原圖混凝土量），圖上與數量表都標明「估算」。
- 平面、縱斷、橫斷、開挖都接上本系統（外包斷面），標準圖進出圖包。

### 固床工＋80φ基樁（G1–G6）
- 原工具的混凝土、模板、鋼筋是「預設值×比例縮放」，改為依斷面幾何沿全長積分（分段 Simpson），並扣除基樁錨入體積。
- 基樁：預設＝原圖 22 支樁位清單（上游排 11、下游排 11），可逐支修改；也可改「自動排樁」（密排區、一般區間距）。按「↧ 目前樁位轉為清單」可把自動結果轉成清單再微調。
- 基樁鋼筋 32φ、16φ 依原圖配筋逐支計算（單位重、損耗、箍筋間距、搭接長皆為參數）；固床工本體鋼筋原圖無表 → 以 2.98 kg/m³ 估算並標明。
- 平面、正視、順水流斷面都畫出基樁。

### 護坡基礎補強（T1–T4）
- 以「左岸／右岸＋起訖樁號」放置；格框內緣＝護岸牆腳往溪心偏 W_gap_slope（預設 1.0 m）；**該樁號沒有護岸時，以設計河寬邊線為準**。
- 座數＝floor((區間長＋間距)÷(單座長＋間距))，整數、置中排列；也可手動指定。左右岸各自一筆，參數分開設。
- 數量依格框幾何：混凝土扣角隅、內外模依角隅斜邊實長、格室漿砌塊石；鋼筋原圖無表 → 34.94 kg/m³ 估算並標明。
- 平面圖畫出每座格框與格室；橫斷面經過補強座的樁號畫出格樑斷面（經過橫樑處為實心，經過格室處為直樑＋塊石），並自動在第一座中間加一個橫斷面。
- 標準圖（平面＋A-A～D-D 剖面＋開口詳圖＋數量表）進出圖包；數量書新增「護坡基礎補強」工作表；工程總表新增「護坡基礎補強」類別。
- 格框外緣若越過中心線（溪床太窄），面板會顯示紅字提醒。

## 三、報表與型錄（C1、C2）
- 三種結構物都進入工程總表：梳子壩、固床工＋基樁各自成一類（不再併在「固床工」），護坡基礎補強另成一類；鋼筋估算列在總表中標為「估算」。
- 結構物型錄加入三種結構物（梳子壩在防砂設施、固床工＋基樁在固床工、護坡基礎補強在護坡），可搜尋「梳子壩、開口壩、基樁、格框、護腳」等關鍵字。
- 新增的左側卡片（護坡基礎補強）預設摺疊。

## 五、移植時發現、請確認的地方
1. **梳子壩側視圖方向**：原工具側視圖的前庭石槽與護坦畫在上游側，但平面圖（有水流箭頭）畫在下游。以平面為準，已把側視圖改到下游側，高度標註移到上游側，護坦長度不再乘 0.72。
2. **固床工＋基樁**：原圖 22 支樁位中，最外側幾支落在兩端基礎斜退區附近；檢核項會列出落在斜退區外的樁數（預設參數為 0）。
3. **護坡基礎補強漿砌塊石**：見上表最後一列，若實際施工嵌槽是高出格樑頂的，請告知，可改回「格樑深＋嵌槽深」。
4. **護坡基礎補強的開挖、回填**：原工具沒有，本版也沒有計算；如需要可下一版加。
5. 護坡基礎補強格框頂取設計河床中心高程（平底），橫斷面設計面若有側坡則與之不完全貼合。
